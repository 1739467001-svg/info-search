# 💡 日柱与八字四柱体系（干支 / 五行 / 命理）

> 整理日期：2026-09-28 ｜ 类型：概念解读 ｜ 置信度：**中**（内容为通行传统文化常识，本轮线上来源（维基/百度百科）被环境拦截未能在线核验，故不附链接）｜ 关联：`relations.md`
> 一句话总结：**"日柱"是公历某一天在"干支纪日"里的代号（一个天干+一个地支）；它属于"八字四柱"体系——年、月、日、时四柱各由一个天干地支组成，日柱的天干叫"日主"，代表你自己，是整张命盘的锚点。它归属"阴阳五行"体系，与《周易》八卦同源但不同流。**

---

## 1. 名词解释（准确版）

**日柱定义：** 出生那一天在六十甲子纪日中的干支组合，如"甲子日""癸酉日"（示意格式）。用出生日期查万年历/排盘工具即可获得。

**四柱八字：**

| 柱 | 时间点 | 传统含义 |
|----|--------|----------|
| 年柱 | 出生年 | 根基、祖辈 |
| 月柱 | 出生月 | 环境、父母 |
| **日柱** | **出生日** | **日主所在，代表本人** |
| 时柱 | 出生时刻 | 后半生、子女 |

**日主 / 日元 / 命主：** 日柱的天干。命理传统以它为中心，其他七个字皆围绕它论（生克、强弱、用神）。所以"你日柱是什么"≈"你的日主是什么五行"。

## 二、底层符号系统

- **十天干**：甲乙丙丁戊己庚辛壬癸
- **十二地支**：子丑寅卯辰巳午未申酉戌亥
- **六十甲子**：天干地支两两配对、遍历一轮 60 组后循环——日柱每 60 天一轮，纪年 60 年一轮
- **天干五行**：甲乙木、丙丁火、戊己土、庚辛金、壬癸水
- **地支五行**：子水、丑土、寅木、卯木、辰土、巳火、午火、未土、申金、酉金、戌土、亥水

### 与其他易学概念的关系与边界

| 概念 | 体系 |
|------|------|
| 日柱 | 八字（命理） |
| 八卦（乾坤震巽坎离艮兑） | 《易经》占卜体系 |
| 五行、阴阳 | 共用哲学基础 |
| 纳音五行 | 六十甲子配五行的另一分支（如"海中金"），常与日柱混提 |

**结论：** 日柱/是"阴阳五行 + 干支"体系的命理应用；**八卦是《易经》"占"体系的符号**。同源（阴阳五行哲学），不同流（命理 vs 占卜），对话里别糊弄成"八字就是八卦"。

## 三、来龙去脉（简史）

- **干支纪日**：殷商甲骨文已有干支表，纪日传统至少三千余年
- **命理定型**：唐代李虚中以年月日三柱论命 → 宋初徐子平补全"时柱"，四柱八字定形（故有"子平术"之称）
- **经典著作**：《渊海子平》（明）、《三命通会》（明·万民英）、《神峰通考》等
- **现代**：八字排盘软件化，民俗传播广泛；学术界并入"术数/传统文化"研究范围

---

## 四、常见问题

1. **"日主"很重要？** 传统命理把它当作盘的中心——只知道日主不知道全局也会被问"你是什么命"；但严格排出完整八字才算"算盘"。
2. **日柱怎么查？** 任何"八字排盘"工具/万年历，输出生日期即可；公历、农历皆可，工具自动换算。
3. **23 点后出生怎么算？** 传统以子时（23:00–1:00）为日界，流派有"早子时/晚子时"之争——同一人可能得到不同日柱，这是流派分歧，不是"错"。
4. **这不是科学**：八字属传统术数，无实证依据；当文化常识、民俗话题了解即可。
