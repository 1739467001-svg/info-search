# 📌 机器学习全景：把 AI 学习技术串成一张地图

> 整理日期：2026-09-28 ｜ 类型：专题调研 ｜ 置信度：**高**（教科书级框架 + 实例与常识交叉）｜ 关联：`relations.md`（本文是连接各节点的"地图文档"）
> 一句话总结：**机器学习是总称，深度学习是其中一条通往网络的路，卷积神经网络是这条路上处理图像的经典车型，强化学习是"试错学"另一条路，持续学习则研究"怎么让车开久了不忘记旧的路线"。**

---

## 1. 一张图看懂关系

```
机器学习 ML（总称：让程序从数据中学习规律，而非人工写规则）
 ├── 传统机器学习（特征靠人来设计）
 │    线性回归 / 决策树 / SVM / 聚类…（小数据、可解释）
 ├── 深度学习 DL（特征自动学习；需要大数据 + 算力）
 │     ├── 卷积神经网络 CNN（图像领域）
 │     ├── 循环网络 RNN/LSTM（时序）
 │     └── Transformer（当今语言/多模态的主流架构，→大语言模型）
 ├── 强化学习 RL（与监督/无监督不同的**第三条路线**）
 │     └── 智能体试错 + 奖励 → AlphaGo / 机器人 / RLHF 训大模型
 └── 持续学习 CL（不是架构，是"课程表"：学新任务不忘旧任务）
```

**一个比喻：** 机器学习是整个烹饪界；深度学习是"高档现代餐厅"这一流派；CNN 是专门做"图像菜"的那口锅；强化学习是"盲停电竞"——没有菜谱，靠试吃打分；持续学习则是"不停换菜品的自助餐厅"对厨师的终身要求。

## 2. 四个词的逐个解释

### 机器学习（Machine Learning，ML）
- **定义**：Tom Mitchell(1997)：程序在任务上、以某种度量表现，若随经验 E 改进该度量，则称它在学习。
- **分类**：有监督（有标签样本）、无监督（无标签，自己找规律）、半监督、强化。
- **关键转变**：从"人类写规则"到"程序自己从数据中发现规则"——这是所有下游概念的根本。

### 深度学习（Deep Learning，DL）
- ML 的子集：多层神经网络自动提取特征（端到端），配合大数据和 GPU 兴起而爆发（2012 AlexNet 为标志）。
- **与传统机器学习的区别**：特征工程还在靠设计者手工做；DL 把这步"自动化"。
- 代表架构：CNN（→本文兄弟文档）、RNN/LSTM、Transformer（大语言模型底座，待研究）。

### 强化学习（Reinforcement Learning，RL）
- **与监督/无监督并列的第三条路线**：没有标注答案，智能体通过"动作→环境反馈（奖励）→策略更新"循环中学会最大化长期奖励。
- 数学底座：马尔可夫决策过程（MDP）；经典成就：AlphaGo（2016 击败李世石）、Atari 游戏。
- **与大模型的关系**：RLHF（人类反馈强化学习）把 RL 引进 ChatGPT 等模型的对齐（alignment）——这是 RL 当不成的主要应用场景。

### 持续学习（Continual / Lifelong Learning，CL）
- 不是网络架构，而是"学习过程的属性设定"：数据流式到达（任务 A → B → C…），要求模型在新任务上进步的同时不遗忘旧任务——对抗"灾难性遗忘（catastrophic forgetting）"。
- 三条主流策略：① 正则化/参数冻结（如 EWC 弹性权重固定）；② 经验重放（把旧样本存进/replay buffer，混合训练）；③ 动态架构（按新任务扩展网络，不碰老参）。
- 为什么现在重要：真实世界的 AI 系统（如持续更新的推荐、对话机器人）永远在学习新数据；端侧设备还要求"设备上终身学习"（on-device continual learning）。

## 三、概念辨析（易混四个词）

| 词 | 是"什么层" | 最易乱的点 |
|----|-----------|-----------|
| 机器学习 | 学科总纲 | 是"找规律"的总称 |
| 深度学习 | 学习学的子流派 | 别以为"越深=越全"；它只是 ML 的路之一 |
| 强化学习 | 另一种训练范式 | 不归 DL 管；和监督学习并列 |
| 持续学习 | 学习方向/设置 | 不是第四种机器学习方式，是给已学模型追加要求的"课程设置" |
