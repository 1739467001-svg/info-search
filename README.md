# 📚 Info Search · 信息搜集笔记本

一个用于信息搜集与笔记记录的仓库：输入关键词，生成结构化的专题研究文档。

## 如何使用

1. 告诉我你想查询的关键词（一个或多个）。
2. 我会联网检索相关资料（概念、内容、项目案例、多维评价等）。
3. 每结束一个话题，我会在新文档 `topics/关键词.md` 中整理成结构化笔记，并更新下方索引。
4. 文档按统一模板生成，保证可读性和可检索性。

## 目录结构

```
info-search/
├── README.md                  # 仓库说明 + 话题索引
├── templates/
│   └── topic-template.md      # 专题笔记模板
└── topics/                    # 所有话题的笔记
    └── <关键词>.md
```

## 文档模板说明

每篇专题笔记固定包含以下模块（详见 `templates/topic-template.md`）：

1. **概念解释** — 这个词是什么、怎么理解
2. **内容涉及** — 涵盖哪些方面/子领域
3. **项目举例** — 代表性项目、产品、案例（附带链接）
4. **多维评价** — 优点/缺点、适用场景、发展趋势、横向对比
5. **参考来源** — 检索到的参考资料链接
