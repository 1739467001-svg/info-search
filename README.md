# 📚 Info Search · 信息搜集笔记本

一个用于信息搜集与笔记记录的仓库：输入关键词 / 概念 / 书名，生成结构化文档。

## 三种用法（直接发给我即可）

| 你发什么 | 我做什么 | 输出位置 | 模板 |
|----------|----------|----------|------|
| 📌 一个关键词（如"大模型"） | 联网多维度调研：概念、内容涉及、项目举例、综合评价 | `topics/` | 专题调研模板 |
| 💡 一个概念/观点（如「帮我理解熵增」） | 深入解读：准确名词解释 + 拆解 + 辨析 + 类比 + 争议 | `concepts/` | 概念解读模板 |
| 📖 一个书名（如《思考，快与慢》） | 帮你读书：主旨 + 章节地图 + 核心观点 + 评价 + 阅读建议 | `books/` | 读书笔记模板 |

## 为什么比直接搜索更好

- **多源合成**：综合多个来源交叉核对，把"共识"和"分歧"分开标注，不迷信单一网页
- **三层可读**：一句话版（30 秒懂）→ 详细版 → 来源链接（可深挖）
- **概念可迁移**：用类比和例子让抽象概念落地，用对比表理清易混概念
- **观点均衡**：同时呈现支持与质疑两方视角，避免只听到一种声音
- **来源可溯**：每篇文档末尾附参考来源，你想深挖随时可查

## 目录结构

```
info-search/
├── README.md                  # 仓库说明 + 话题索引
├── relations.md               # 知识关系图谱（主题间关联）
├── templates/
│   ├── topic-template.md      # 专题调研模板（关键词）
│   ├── concept-template.md    # 概念解读模板（观点/概念）
│   └── book-template.md       # 读书笔记模板（书名）
├── topics/                    # 关键词专题调研
├── concepts/                  # 概念/观点解读
└── books/                     # 读书笔记
```
